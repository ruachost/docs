---
title: "Authentication"
description: "Authenticate WhatsApp API requests with your client ID and API key"
---

The WhatsApp API uses HTTP Basic authentication on every request.

- **Username:** your client ID
- **Password:** your API key

Most HTTP clients construct the `Authorization` header for you. With cURL, pass the credentials using `--user`:

```bash
curl --request GET \
  --url "https://app.notify.ng/api/whatsapp/v1/Connector/GetAll" \
  --user "$CLIENT_ID:$API_KEY" \
  --header "Accept: application/json"
```

The equivalent header has this format:

```text
Authorization: Basic base64(CLIENT_ID:API_KEY)
```

<Warning>
Keep your API key on the server. Do not embed it in browser code, mobile applications, public repositories, or logs. Always send requests over HTTPS.
</Warning>

## Authentication failure

Invalid or missing credentials return HTTP `401 Unauthorized` with API status code `401`.

See [Error codes](/whatsapp/error-codes) for the complete error reference.

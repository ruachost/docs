## Dashboard Walkthrough

This guide mirrors the platform workflow from login to final send, including contact management, sender ID usage, scheduling, and reports.

### 1) Open SMS Module and Compose Screen

Start on the dashboard, open the `SMS MT` module, and click `Compose SMS`.

<img src="/images/dashboard-overview.png" alt="Dashboard overview" /> <img src="/images/dashboard-overview001.png" alt="Dashboard overview (variant)" /> <img src="/images/send-sms.png" alt="Compose SMS screen" />

### 2) Enter Campaign Details

Provide a campaign name and sender ID before adding recipients.

<img src="/images/Click-Campaign-name-to-name-the-campaign.png" alt="Campaign name field" /> <img src="/images/Input-your-SenderID.png" alt="Sender ID input" /> <img src="/images/manage-senderIDs.png" alt="Manage Sender IDs menu" />

### 3) Prepare Contacts

You can type numbers directly, import from file, or select from existing groups.

<img src="/images/contacts.png" alt="Contacts menu" /> <img src="/images/contacts-02.png" alt="Manage groups entry" /> <img src="/images/contacts-03.png" alt="Manage groups table" /> <img src="/images/contacts-04.png" alt="Add group modal" /> <img src="/images/contacts-05.png" alt="Bulk import action from group" /> <img src="/images/contacts-06.png" alt="Import contacts step 1" /> <img src="/images/contacts-07.png" alt="Import contacts step 2" /> <img src="/images/Input-your-contacts.png" alt="Contacts input area" />

### 4) Configure Message Settings

Choose encoding, compose your message, and optionally use Flash SMS.

<img src="/images/data-coding.png" alt="Data coding selector" /> <img src="/images/message-content.png" alt="Message content input" />

### 5) Optional: Schedule Message

If you do not want immediate delivery, enable scheduling before sending.

![Schedule checkbox](/images/schedule-message.png)

### 6) Send Message

Click `Send`, review the message preview and cost breakdown, then confirm.

<img src="/images/send-sms-001.png" alt="Compose screen with send button" /> <img src="/images/send-sms-002.png" alt="Message preview confirmation" />

### 7) Track Delivery and Download Reports

Use `Reports` to monitor status, filter by date range, and export results.

<img src="/images/report.png" alt="Campaign report menu" /> <img src="/images/report02.png" alt="Campaign report list view" />

### 8) Monitor Wallet / Credit

Check wallet/credit balance to ensure sufficient funds before large campaigns.

![Wallet screen](/images/Wallet.png)
